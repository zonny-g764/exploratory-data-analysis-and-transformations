# 📈 Data Visualization, Correlation Analysis & Feature Scaling (Python)

This project focuses on exploratory data analysis (EDA), data visualization techniques, custom correlation calculations, and feature transformation methods using Python.

## 🛠️ Key Topics & Techniques Covered
* **Manual & Library Pearson Correlation:** Calculating Pearson $r$ by hand from mathematical formulas and comparing it with `scipy.stats.pearsonr`.
* **Data Visualization:**
  * Scatterplots with class labels (Iris dataset)
  * Feature distribution analysis using Histograms & Boxplots
  * Quantile-Quantile (QQ-Plots) to check for normality
* **Feature Engineering:** Custom implementation of Min-Max Scaling ($[0, 1]$ normalization) and comparing original vs. scaled distributions.

## 📁 Project Structure
* `exercise_sheet_02.ipynb` - Complete Jupyter Notebook containing all analyses and visualizations.
* `data.csv` - Custom dataset used for non-linear correlation and feature transformation tasks.

## 🚀 Libraries Used
* `pandas`, `matplotlib`, `scikit-learn`, `scipy`
